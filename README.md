# Iris Gaming Wiki

Base de conocimiento de gaming curada por la comunidad, usada por [Iris](https://irisapp.lat) para dar respuestas más precisas mientras jugás.

## Cómo funciona

Iris consulta esta wiki automáticamente cuando detecta que una pregunta tiene contexto específico de un juego. La wiki complementa la búsqueda web con información curada y verificada por la comunidad.
