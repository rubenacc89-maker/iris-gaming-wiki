# Equipo de Recolección — Albion Online

Para recolectar recursos necesitás la herramienta correcta y ropa de recolector que te dé bonus de velocidad y yield.

---

## Herramientas por oficio

| Herramienta | Recurso que recolecta |
|-------------|----------------------|
| Hacha de maderero | Troncos / Madera |
| Pico de minero | Mineral / Metal |
| Hoz de cosechador | Fibra / Tela |
| Cuchillo de peletero | Piel bruta / Cuero |
| Martillo de cantero | Piedra bruta / Bloques |
| Caña de pescar | Peces |
| Martillo de demolición | Recursos de edificios |

---

## Atuendos de Recolector

Cada oficio tiene su propio set completo (gorro, overol, botas, mochila). El set completo da bonus de velocidad de recolección y yield de recursos.

| Oficio | Set |
|--------|-----|
| Cosechador | Gorro + Overol + Botas + Mochila de cosechador |
| Maderero | Gorro + Overol + Botas + Mochila de maderero |
| Minero | Gorro + Overol + Botas + Mochila de minero |
| Peletero | Gorro + Overol + Botas + Mochila de peletero |
| Cantero | Gorro + Overol + Botas + Mochila de cantero |
| Pescador | Gorro + Overol + Botas + Mochila de pescador |

---

## Tips

- Subí el tier de tu herramienta y ropa al mismo tier de recurso que querés recolectar
- La mochila de recolector amplía el inventario específicamente para ese tipo de recurso
- Usar el set completo del mismo oficio maximiza la eficiencia
- Zonas azules y amarillas son seguras para recolectar; zonas rojas y negras tienen más recursos pero riesgo de PvP
